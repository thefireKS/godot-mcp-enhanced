# audit

> Operation audit log (G3). action=get_log reads {project}/.godot/mcp_audit.jsonl as stats and replay (operation counts / risk highlights / recent entries / time range); action=suggest_rollback gives an honest rollback suggestion for one entry (created files can be deleted / project.godot before_values / everything else via Git). Write/destructive operations are logged automatically by the audit after-middleware (changed_files are project-relative, PII guarded).
