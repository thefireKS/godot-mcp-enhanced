# nav

> Navigation operations. create_region: create a NavigationRegion3D (optionally bake). bake_mesh: bake the navigation mesh (slow). create_agent: create a NavigationAgent3D. set_params: set navigation parameters. create_link: create a NavigationLink3D. query_path: query a 3D navigation path. Runtime operation, affects only the current execution context. To persist, edit the .tscn file.
