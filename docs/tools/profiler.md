# profiler

> Profiling. snapshot: FPS/memory/draw calls/physics stats. start/stop: start/stop a profiling session. get_data: frame-level data with multi-dimension sampling, p99 percentiles, regression trend detection, memory trend and render stats. get_active_processes: walk the scene tree for nodes with _process/_physics_process. get_signal_connections: list all signal connections in a subtree. Runtime operation, affects only the current execution context. To persist, edit the .tscn file.
