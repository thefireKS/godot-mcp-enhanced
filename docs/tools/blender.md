# blender

> Procedural modeling in Blender. action=execute_bpy: the AI writes a bpy snippet, it runs headless and the result is exported as glb into res://. (⚠️ bpy is full Python: the threat surface is host RCE, an order of magnitude above the execute_gdscript sandbox. bpy code goes through a sandbox scan (known dangerous API patterns, list not published so the boundary can't be probed) + a double opt-in bypass, same philosophy as execute_gdscript; the glb export target is additionally constrained by resolveWithinRoot. Local single-user trust model.)
