# godot_list_dynamic_routes

> Three-level lazy discovery: query available tools (static registry + dynamic discovery). No args returns category counts; search does fuzzy matching; category lists one category's tools; tool returns one tool's full schema.

| Property | Value |
|------|-----|
| Layer | headless |
| Safety level | safe |
| Needs Godot | yes |
| Needs editor | no |
| Read-only | yes |
| Long-running | no |

## Parameters

| Parameter | Type | Required | Description |
|------|------|------|------|
| `category` | string |  | Category name → that category's tool list (brief + param names, lean view). With includeSchemas=true returns the full schemas in one go. |
| `search` | string |  | Keywords (space-separated); all must match; name matches rank first. Max 20 results, no schemas. |
| `tool` | string |  | Tool name → that tool's full schema (highest priority, overrides search/category). |
| `includeSchemas` | boolean |  | Use with category: return full schemas of every tool in the category at once (large, use sparingly). |
