# uid

> File UID management (Godot 4.4+). scan: find resources missing .uid and orphan .uid files. get: look up file UIDs (batch). set: write .uid (a given uid / generate for one file / fix_missing in batch). check_refs: detect dangling uid:// references (checked against the project's .uid set only; a reference whose uid dangles but whose ext_resource has a path fallback still loads fine — it is counted as dangling as a diagnostic hint, not a broken link). Runtime operation, affects only the current execution context. To persist, edit the .tscn file.
