# csv_to_resources

> CSV → Resource batch generation. Reads a CSV (class_path points at a GDScript Resource class), names files by filename_column, writes .tres files into output_dir. CSV rows are read with GDScript FileAccess.get_csv_line (never spliced into script source, injection-safe). output_dir goes through the resolveWithinRoot sandbox (TS pre-check); filename whitelist (GDScript regex + rejects .. segments).
