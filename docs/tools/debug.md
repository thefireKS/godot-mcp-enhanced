# debug

> Interactive debugger — breakpoint management + Phase 2/3 debugger integration (editor-only). Phase 1: set/clear/list breakpoint (via the CodeEdit gutter; scripts open automatically since CMP-14). Phase 2: stack_trace (call stack + variables) / inspect_frame (switch frame + read variables) / evaluate (REPL in the breakpoint context). Phase 3: step (into/over) / continue (run to the next breakpoint) / pause (request a break) / reload_scripts (hot reload). ⚠️ editor-only: needs GODOT_MCP_MODE=editor + the Godot plugin installed + the game running (F5). ⚠️ Phase 2/3 need the game paused at a breakpoint (step/inspect/evaluate) or running (pause/reload).
