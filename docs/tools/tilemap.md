# tilemap

> TileMap/TileMapLayer cell operations. Read: tilemap_read, tilemap_copy. Write: tilemap_set_cell, tilemap_erase_cell, tilemap_fill_rect, tilemap_clear, tilemap_paste, tilemap_set_transform. Pass scene_path to work on any scene, otherwise the main scene is used. Runtime operation, affects only the current execution context. To persist, edit the .tscn file.
