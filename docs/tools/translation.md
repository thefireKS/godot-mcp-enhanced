# translation

> Translation files. read: read CSV/PO translation entries (languages/key-values). write: write/create a Godot-compatible CSV translation table (key + one column per language; CSV→.translation compilation is done by the editor import). register: register .translation/.po files in project.godot (translations array; remove=true removes them).
