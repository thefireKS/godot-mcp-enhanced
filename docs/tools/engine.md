# engine

> Live ClassDB introspection + node method calls (editor-only): query the classes/methods/properties/signals/enums the running engine actually has, or call an instance method on a node in the editor scene tree. class_info: full structure of one class (properties/methods/signals/enums/inheritance); default no_inherit=true shows only its own members. search: substring match on class names (returns a {name, parent} list, max 100). Then use class_info for the members. get_inheritance: the class inheritance chain (from the class up to Object). call_method: call an instance method on a node in the editor scene tree (like node.call). args are coerced to the declared parameter types ([1,2,3] becomes a Vector3). The deny-list blocks dangerous methods by default (free/queue_free/set_script/call/emit_signal etc.); env GODOT_MCP_EDITOR_CALL_DENYLIST_OVERRIDE adds to it (union with the default list, can only add; an explicit empty string lifts it). Calls cannot be undone (the response says undoable=false). ⚠️ Fills the gap in the docs tool: docs is a static 4.7 snapshot (no third-party addons/custom classes/4.6/4.8 differences), engine is the running engine's real ClassDB. ⚠️ editor-only: headless mode returns EDITOR_ONLY (ClassDB is blocked in the sandbox, so it goes through the editor layer).
