# runtime_assert

> Runtime assertions: check node state / scene structure / on-screen text / performance / screenshot diff in the running game. The agent can call it at any time without going through workflow.dev_loop. Everything needs the game bridge (game_bridge_install first + game running).

## Parameters

| Parameter | Type | Required | Description |
|------|------|------|------|
| `action` | enum (5 values) | ✓ | Assertion type |
| `project_path` | string |  | Project path (required for screenshot_diff: resolves where user:// screenshots land) |
| `path` | string |  | node_state: node path (e.g. /root/Main/Player) |
| `expect` | object |  | node_state: expected property key/values (e.g. {"health": 100, "position": {"x": 0}}) |
| `tolerance` | number |  | node_state/perf: numeric tolerance (default 0, exact match) |
| `nodes` | array |  | scene_structure: expected nodes |
| `text` | string |  | screen_text: text to find |
| `present` | boolean |  | screen_text: true = assert the text is present (default), false = assert it is absent |
| `baseline` | object |  | perf: expected performance baseline (e.g. {"fps": 60}) |
| `reference` | string |  | screenshot_diff: reference screenshot path (res://, project-relative or absolute; must be whitelisted) |
| `threshold` | number |  | screenshot_diff: per-pixel difference threshold (0-1, default 0.12). A pixel counts as different only when its normalised RGB distance is strictly greater; smaller is stricter |
| `max_diff_ratio` | number |  | screenshot_diff: max share of differing pixels (0-1, default 0.05). Pass 0 for strict pixel regression; for ordinary visual regression calibrate against a known-good pair with the same layout (measured ≈0.176 for such a pair in this repo, don't go below that order) |
