# testing

> McpTestSuite test framework (editor-only): runs GDScript test suites written by the AI (`extends McpTestSuite`, placed in `res://tests/` or `addons/godot_mcp_server/testing/suites/`). run: discover and run suites; returns structured passed/failed/skipped/total/failures. manage: op="results_get" fetches the partial results of the last run (after a timeout/interruption). ⚠️ P2-12 phase 2: runs as an async coroutine, yielding the main loop after each test (heartbeat keeps pinging), so long suites work (total budget 290s; on timeout split the run with suite=). ⚠️ editor-only: headless mode returns EDITOR_ONLY. Needs `GODOT_MCP_MODE=editor` and the Godot plugin installed.
