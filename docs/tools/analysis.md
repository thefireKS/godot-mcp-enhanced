# analysis

> Static understanding-layer analysis (no Godot needed). action=signal_map lists all signal connections in the project (.tscn [connection] declarations + .gd connect/emit references, sources labelled separately); action=impact_check assesses blast radius before a change — for a signal, lists all connectors/emitters/listeners; for a script, the scenes and nodes that reference it; for a scene, its connections/scripts/where it is instanced. Known blind spots: runtime-built signal names and autoload-to-autoload connections are invisible.
